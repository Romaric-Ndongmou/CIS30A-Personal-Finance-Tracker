# CIS30A-Personal-Finance-Tracker
CIS30A Course Project - Option 2 Personal Finance Tracking Program

## Project Overview
This project is a beginner-level Personal Finance Tracking Program built using Python. 
It allows users to add income and expenses, view financial summaries, update and delete transactions, and save results to a text file.

## Features
- Add Income
- Add Expense
- Update Transactions
- Delete Transactions
- View Financial Summary
- Save summary to finance_summary.txt
- Uses Classes and Inheritance
- Uses Custom Module
- Includes File Operations and Exception Handling

## How to Run
1. Download the project files.
2. Make sure main.py, utils.py, and finance_models.py are in the same folder.
3. Run main.py using IDLE (F5).
